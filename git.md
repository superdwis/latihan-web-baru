git init (untuk inisialisai project awal)

git config user.name "nama kalian" (utnukconfigurasi nama)
git config user.email "email kamian" (untuk konfigurasi email github)

git add . (untuk menambah file ke github)

git commit -m "pesan commit" (untuk commit file yg sudah di add ke github)

git remote add origin https://github.com/superdwis/latihan-web-baru.git -> diambil dari akun github

git branch -M main

git push -u origin main
